### MySQL基础
1. 数据库连接
	-  第三方数据库软件如：Dbeaver接入
	-  终端接入
		`mysql -u 用户名 -p 密码 -h 主机地址`
2. 展示mysql相关信息
``` mysql
status;
```
3. 显示数据库名称
``` mysql
show databases;
```
4. 打开数据库
``` mysql
use 库名;
```
5. 展示数据表名称
``` mysql
show tables;
```
6. 显示表结构
``` mysql
describe 表名;
show columns from 表名;
```
7. 显示表创建过程
``` mysql
show create table 表名;
```
8. 清空数据表
``` mysql
delete from 表名;
truncate table 表名;
```
9. 删除数据表
``` mysql
drop table 表名;
```
10. 删除数据库
``` mysql
drop databases 表名;
```
11. 退出数据库连接
``` mysql
exit
```
### 常用SQL语句
1. SELECT 语句：用于从表钟选取数据
``` SQL
select 列名 from 表名;
select * from 表名;
```
- order by语句：排序
	升序排序：`select 列名 from 表名 order by 列名;`
	降序排序：`select 列名 from 表名 order by 列名 desc;`
- where 语句：有条件的选取表中数据
	`select 列名 from 表名 where 列名 运算符 值;`
- and 和 or 语句
	- and：两者都成立
		`select 列名 from 表名 where 列名 运算符 值 and 列名 运算符 值;`
	- or：两者有一个成立
		`select 列名 from 表名 where 列名 运算符 值 or 列名 运算符 值;`
- limit 语句：控制输出（limit前一位数字表示**起始行**，后一位数表示**行数**）
	`select 列名 from 表名 limit 0,1;`   这里表示从第一行开始查找一行
2. INSERT INTO 语句：用于向表格中插入新行
``` SQL
insert into 表名 values (值1，值2,...);
insert into table_name (列1,列2,...) values (值1，值2，...);
```
3. DELETE 语句：用于删除表中到底行
``` SQL
delete from 表名 where 列名 = 值;
delete * from 表名;
```
4. UPDATE 语句：用于修改表中数据
``` SQL
update 表名 set 列名 = 新值 where 列名 = 某值;
```
5. MySQL注释符
	`/**/`
	`#`
	`--`
- 注释符可替换空格
``` MySQL
select/*123*/列名/*123*/from/**/表名; 
```
- 内联注入
	在 `/**/`中加了`!`，那么后面的内容就会被执行
``` mysql
select/*123*/列名/**/from/*!表名*/;
```
- 单行注释符后面加换行也可以执行
``` mysql
select * from#asdka
表名;
```
### MySQL系统表
- information_schema表下三个重要表
	-  schemata表
		`show databases;` 当前表下查询可得到
			schemata_name列 —— 所有数据库名
	-  tables表
		`show tables from 上面查询到的库名` 当前表下查询可得到
			table_name列 —— 所有表名
			table_schemata列 —— 表来自哪个数据库
	-  columns表
		`show columns from 上面查询到的库名.表名;` 当前表下查询可得到
		column_name列 —— 所有列名
		table_name列 —— 列来自哪个表
		table_schema列 —— 列来自哪个数据库
