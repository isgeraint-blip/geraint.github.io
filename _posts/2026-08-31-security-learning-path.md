> 仅用于**授权**测试与学习，遵守《网络安全法》。

## 一、基础

- 网络协议：HTTP/HTTPS、TCP/IP、DNS
- 操作系统：Linux 基础命令、Windows
- 编程：Python / Bash

## 二、信息收集

- 子域名枚举、端口扫描、指纹识别
- 搜索引擎 / 资产测绘
- GitHub 信息泄露、备案信息

## 三、常见 Web 漏洞

| 类型 | 说明 |
|---|---|
| SQL 注入 | 语句拼接导致数据库注入 |
| XSS | 跨站脚本 |
| SSRF | 服务端请求伪造 |
| 越权 | 水平/垂直权限绕过 |
| 文件上传 | 上传点绕过 getshell |
| RCE | 远程命令/代码执行 |

## 四、进阶

- 内网渗透、横向移动、权限提升
- 代码审计、常见框架漏洞
- 通用漏洞（通杀）挖掘与整理

## 五、合规与成果

- 只测授权目标
