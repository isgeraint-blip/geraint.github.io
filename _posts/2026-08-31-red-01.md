> **阵营**：红队　**分类**：红队 / 渗透测试 / 常用软件脚本

- 更新
``` cmd
# 更新模板
nuclei -update-templates

#更新 Nuclei
nuclei -update
```
- 使用手册
	`REAEME.md` 文件查询 / `nuclei -h` 
- 基本使用
``` cmd
# 扫描单个目标
nuclei -u <Url>

# 扫描多个目标
nuclei -i <list.txt>

# 指定模板扫描
nuclei -u <url> -t <poc.yaml/poc_dir>

# 输出结果
nuclei -u <url> -o <results.txt>
nuclei -u <url> -o <results.json> -json -irr

# 调试模板
nuclei -u <url> -debug -t <poc.yaml>
```
