> **阵营**：红队　**分类**：红队 / 渗透测试 / 内网渗透

常用模块：Exploit（漏洞利用模块）、Payload（漏洞利用成功后执行的代码）、Post（后渗透模块）
### Exploit
查看可用exploit：`show exploits` 
搜索exploit：`search [内容]` 
使用exploit：`use [搜索出的索引序号]` 
	综合考虑：目标操作系统版本、服务版本、架构、利用条件
### Payload
接入载荷，建立连接
### Post
``` msf
# 搜索所有后渗透模块 
search post/ 

# 搜索 Windows 信息收集类模块 
search post/windows/gather
```
信息收集、权限提升、横向移动、持久化
``` msf
# --- 信息收集 --- 
use post/windows/gather/system_info # 获取系统信息 
use post/windows/gather/hashdump # 提取 SAM 密码哈希 
use post/windows/gather/screen_spy # 屏幕截图 
use post/windows/gather/enum_applications # 枚举已安装应用 
use post/windows/gather/enum_logged_on_users # 枚举已登录用户 

# --- 系统管理 --- 
use post/windows/manage/migrate # 进程迁移（规避杀软） 
use post/multi/manage/shell_to_meterpreter # 将普通 Shell 升级为 Meterpreter 

# --- 权限提升 --- 
use post/windows/escalate/getsystem # 尝试 SYSTEM 提权 

# --- 持久化 --- 
use post/windows/manage/persistence_exe # 可执行文件持久化
```
