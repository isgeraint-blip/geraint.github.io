## 一、管理控制台与基础配置
### 1.1 禁用不必要的服务

- **操作步骤**：关闭未使用的端口（如 SOAP、RMI、JMX 等），通过控制台 `应用程序服务器 > server1 > 端口` 检查。
- **检测方法**：检查端口状态，确认未使用的端口已关闭。
### 1.2 修改默认端口

- **操作步骤**：更改默认管理端口（9060/9043）和应用端口（9080/9443）。
- **检测方法**：通过网络扫描工具确认端口变更。
### 1.3 限制访问来源

- **操作步骤**：配置防火墙规则，仅允许可信 IP 访问管理控制台和应用端口。
- **检测方法**：使用非授权 IP 访问测试。
## 二、用户认证与权限控制
### 2.1 强化管理员账户

- **操作步骤**：删除默认用户（如 admin），创建自定义管理员账号。启用密码策略：`安全性 > 全局安全性 > 用户账户存储库` 设置密码复杂度（长度≥12，包含大小写、数字、符号）。
- **检测方法**：检查用户列表，确认默认用户已删除，自定义管理员账号已创建并符合密码策略。
### 2.2 角色最小化权限

- **操作步骤**：分配权限时遵循最小原则：`Administrator` 仅限核心管理员；`Operator` 仅监控权限；`Deployer` 仅部署应用。
- **检测方法**：检查用户角色分配，确认权限分配符合最小化原则。
### 2.3 集成企业级认证

- **操作步骤**：配置 LDAP/AD 集成（传统版：`联合存储库`；Liberty 版：在 `server.xml` 中配置 `<ldapRegistry>`）。
- **检测方法**：通过登录测试，验证 LDAP/AD 集成是否正常工作。
## 三、通信安全（SSL/TLS）
### 3.1 禁用弱加密协议

- **操作步骤**：禁用 SSLv3、TLS 1.0/1.1，仅启用 TLS 1.2+：
    - 传统版：修改 SSL 配置，`SSLConfig > QualityOfProtection` 设置，禁用旧协议。
    - Liberty 版：在 `server.xml` 中添加：
```xml
<ssl id="defaultSSLConfig" sslProtocol="TLSv1.2" />
```
- **检测方法**：使用 SSL 测试工具检查支持的协议版本。
### 3.2 证书管理

- **操作步骤**：替换默认证书，使用 CA 签名的正式证书。定期轮换密钥（建议每年一次）。
- **检测方法**：检查证书配置，确认使用正式证书，密钥轮换机制正常工作。
## 四、应用与数据安全
### 4.1 应用部署策略

- **操作步骤**：启用应用安全域（`企业应用 > app_name > 安全性`），限制应用的权限。关闭应用的自动部署功能（传统版：`应用程序服务器 > server1 > 应用程序部署`）。
- **检测方法**：检查应用权限设置，确认自动部署功能已关闭。
### 4.2 数据加密

- **操作步骤**：启用数据库连接加密（如 JDBC 使用 SSL）。加密敏感配置文件（Liberty 版可使用 `securityUtility` 工具加密）。
- **检测方法**：检查数据库连接配置，确认使用加密连接，配置文件加密正常工作。
## 五、日志与监控
### 5.1 启用审计日志

- **操作步骤**：传统版：`日志和跟踪 > server1 > 审计日志`，记录管理员操作。Liberty 版：在 `server.xml` 中添加：
```xml
<logging consoleLogLevel="INFO" />
<audit>
  <auditFile fileName="audit.log" />
</audit>
```
- **检测方法**：检查日志文件，确认审计日志记录完整。
### 5.2 实时监控

- **操作步骤**：配置日志聚合工具（如 ELK）分析日志。设置警报规则（如频繁登录失败、异常请求）。
- **检测方法**：验证日志聚合工具的报警功能，确认警报规则正常工作。
## 六、补丁与版本管理
### 6.1 升级策略

- **操作步骤**：定期更新至最新版本（传统版建议至少升级到 8.5.5 Fix Pack 25+，Liberty 版使用 22.0.0.3+）。订阅 IBM 安全公告（[IBM PSIRT](https://www.ibm.com/support/pages/ibm-security-bulletins "IBM PSIRT")）。
- **检测方法**：检查已安装的版本信息，确认订阅 IBM 安全公告。
### 6.2 漏洞扫描

- **操作步骤**：使用工具（如 Nessus、Qualys）定期扫描 WebSphere 实例。
- **检测方法**：查看扫描报告，确认无高危漏洞。
## 七、Liberty 版专项配置
### 7.1 最小化功能

- **操作步骤**：在 `server.xml` 中仅启用必要功能（如删除 `<feature>adminCenter-1.0</feature>` 若不需要）。
- **检测方法**：检查 `server.xml` 文件，确认仅启用必要功能。
### 7.2 动态更新防护

- **操作步骤**：禁止运行时配置热更新：
```xml
<applicationMonitor updateTrigger="disabled" />
```
- **检测方法**：尝试进行运行时配置更新，确认更新被禁止。
## 八、操作系统加固
### 8.1 非特权用户运行

- **操作步骤**：使用非 root 用户（如 `wasuser`）启动服务：
```bash
su - wasuser -c "/opt/IBM/WebSphere/AppServer/bin/startServer.sh server1"
```
- **检测方法**：检查进程用户，确认服务以非 root 用户运行。
### 8.2 文件权限控制

- **操作步骤**：设置关键目录权限（如 `appServer` 目录仅允许 `wasuser` 读写）：
```bash
chown -R wasuser:wasgroup /opt/IBM/WebSphere/
chmod -R 750 /opt/IBM/WebSphere/
```
- **检测方法**：检查文件系统权限，确认关键目录权限设置正确。
## 九、备份与恢复
### 9.1 定期备份配置

- **操作步骤**：传统版：使用 `backupConfig.sh` 备份配置。Liberty 版：备份整个 `usr/servers/[server_name]` 目录。
- **检测方法**：检查备份文件，确认备份文件存在且完整。
### 9.2 灾难恢复测试

- **操作步骤**：每季度执行一次配置恢复演练。
- **检测方法**：执行恢复演练，确认备份文件能够正常恢复。
## 生效步骤

```bash
# 停止 WebSphere 服务
./stopServer.sh server1

# 启动 WebSphere 服务
./startServer.sh server1
```
## 检测工具

- 使用 `curl -I http://localhost:端口` 检查 HTTP 响应头是否隐藏版本信息。
- 访问 `http://服务器IP:端口/不存在的路径` 验证自定义错误页面是否生效。
